Política de privacidad — lab-raza-real (aplicación de pruebas) Última actualización: 1 de noviembre de 2026 1. Qué es esta aplicación Es una aplicación de pruebas técnicas para verificar una integración con la API de WhatsApp Business. No ofrece servicios al público. Responsable: Camilo Villa Polo, contacto: cv332192@gmail.com. 2. Datos que se reciben Cuando un número autorizado interactúa con el número de prueba, la aplicación recibe de Meta: el número de teléfono, el nombre de perfil, el contenido y la hora del mensaje, y los estados de entrega. 3. Finalidad Solo se usan para comprobar el funcionamiento técnico de la integración. No se usan para publicidad ni se venden. Se almacenan en servicios de alojamiento y base de datos contratados por el responsable, necesarios para operar la prueba. 4. Conservación Los datos se eliminan al terminar las pruebas y, a más tardar, en 30 días calendario. 5. Derechos Conforme a la Ley 1581 de 2012, puedes conocer, actualizar, rectificar y solicitar la supresión de tus datos escribiendo a [CORREO]. 6. Cambios Esta política puede actualizarse; la fecha indica la última versión.
